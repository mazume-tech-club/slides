資料を追加する

  1. 01 your-topic/index.html を作る。ディレクトリ名がURLになるので、英小文字とハイフンにする。
  2. 02 ../assets/theme.css と reveal.js の CDN を読むと、この一覧と同じ見た目に揃う。骨組みは README にある。
  3. 03 このページの「資料」にカードを足し、README の一覧にも1行足す。
  4. 04 main へマージすると GitHub Actions が Pages へ出す。新しいディレクトリは、除外している .git と .github 以外ならそのまま配信される。

閲覧には CDN（reveal.js とフォント）へのネットワークが要る。ローカルではリポジトリ直下で python3 -m http.server を起動する。
